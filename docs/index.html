Hand off coding-agent sessions without losing context

agent-handoff reads session exports from tools like OpenCode and Codex, normalizes them into a shared handoff spec, and emits a continuation package for your next agent. Detect the format first, then convert — or try detection right here in your browser.

OpenCode JSON Codex JSONL Markdown handoffs Chat JSON CLI + browser demo

Why agent-handoff?

  1. Session finished?
  2. Where do you want to continue?
  3. agent-handoff picks it up.
session-export.json — raw OpenCode export 
{
  "info": {"id": "ses_a8f2…", "title": "Fix login redirect", "createdAt": 1792435324365},
  "messages": [
    {"info": {"role": "user", "id": "msg_01"}, "parts": [
      {"type": "text", "text": "Add JSON 401 for AJAX login when session expires…"}
    ]},
    {"info": {"role": "assistant"}, "parts": [
      {"type": "tool", "tool": "edit", "state": {"status": "completed",
        "input": {"filePath": "app/views.py", "oldString": "…", "newString": "…"},
        "output": "Updated decorator login_required_json."}},
      {"type": "text", "text": "I updated the decorator; running pytest…"},
      {"type": "tool", "tool": "bash", "state": {"status": "completed",
        "input": {"command": "pytest tests/test_auth.py -q"}, "output": "…12 lines…"}}
    ]},
    …4 more turns, token usage, part IDs, nested state…
  ]
}
→
codex-task.json — handoff for Codex 
"user_message":
  Continue: add integration test for the login JSON endpoint.

## Objective
Hand off: add integration test for the API route.

## Context
Add JSON 401 for AJAX login when session expires.

## Prior work
Updated app/views.py (login_required_json).
pytest tests/test_auth.py — passing locally.

## File changes
• app/views.py (modified)

## Constraints
• Continue from summarized state; don't redo completed work.
• Prefer editing listed files before creating new ones.

One command: agent-handoff convert -f auto -t codex -i session-export.json -o codex-task.json

Install

pip install agent-handoff

For development: pip install -e ".[dev]" from the repository.

CLI examples

Detection runs automatically with --from auto (default for inspect).

$ agent-handoff detect -i session.json
format: opencode_export
parser: opencode
version: export-v1-tools
signature: info+messages+parts
confidence: 0.95
$ agent-handoff convert -f auto -t codex -i rollout.jsonl -o task.json
Wrote task.json
$ agent-handoff detect -i mystery.json
format: unknown
message: This format is not recognized.
